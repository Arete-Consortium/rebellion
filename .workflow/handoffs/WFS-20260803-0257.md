## Context for Next Session

**Architecture — the locked pattern.** The campaign-gated HUD replacement pattern is the canonical mechanism for any future campaign-specific HUD work. The flow:

```
Campaign plugin (e.g. TriglavianInvasionPlugin)
├── inits CombatWheelAdapter
├── adds *BindPlugin (adapter projections, owned by campaign module)
├── OnEnter(GameState::Playing): spawn_<hud_chain>.run_if(in_<campaign>)
└── OnExit(GameState::Playing): despawn_<hud>.run_if(in_<campaign>)

Standard HUD plugin
└── All systems: .run_if(not_in_<campaign>)  ← gates out during campaign

Public run conditions live in src/games/mod.rs
```

**Test isolation pattern.** `build_triglavian_campaign_app` mirrors production wiring instead of importing the full plugin. Window-dependent systems stay out of headless tests.

**Gotchas discovered:**
- `Material2dPlugin` doesn't init `Assets<Mesh>` or `Assets<ColorMaterial>` in 0.15 — headless tests need both `app.init_resource::<Assets<Mesh>>()` and `app.init_resource::<Assets<bevy::sprite::ColorMaterial>>()`
